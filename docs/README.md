## Quick Overview

HAWK Security is a comprehensive security monitoring and vulnerability management platform that helps organizations identify, track, and remediate security vulnerabilities across their systems.

### Key Features
- Multi-source vulnerability scanning from free databases
- Real-time security alerts and notifications
- AI-powered chatbot for security assistance
- System monitoring and OEM tracking
- User authentication and profile management
- Responsive design with modern UI components

### Architecture
- **Frontend**: React + TypeScript + Vite
- **Styling**: Tailwind CSS + shadcn/ui components
- **Backend**: Supabase (Database, Auth, Edge Functions)
- **State Management**: React hooks + TanStack Query
- **Notifications**: Email, SMS, and in-app notifications
